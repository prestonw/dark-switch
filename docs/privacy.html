Privacy Policy

Last updated: June 2026

Overview

Dark Switch does not collect, store, transmit, or share any personal information. This policy explains what the app does and does not do with your data.

Data collected

None. Dark Switch does not collect any data of any kind.

Local storage

Dark Switch saves a configuration file to your Mac's local Application Support directory. This file contains only your chosen default appearance mode and any per-app rules you have set. It never leaves your device.

System permissions

Dark Switch requests permission to control System Events via Apple Events. This permission is used solely to read and set the macOS system appearance (light or dark mode). No other actions are performed and no information is read from System Events beyond the current appearance state.

You can revoke this permission at any time in System Settings under Privacy & Security → Automation.

Network access

Dark Switch does not make any network requests. There are no analytics, crash reporters, update checks, or external services of any kind.

Third parties

No data is shared with any third party. There are no third-party SDKs, trackers, or advertising frameworks included in the app.

Children

Dark Switch does not collect data from anyone, including children under the age of 13.

Changes to this policy

If this policy changes in a material way, the updated version will be published at this URL with a revised date.

Contact

Questions about this policy can be directed to the project via the issue tracker on the source code repository.
